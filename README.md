PRESUPUESTOS · GONZÁLEZ CONSTRUCCIONES
=====================================

PARA PUBLICARLA ONLINE (gratis, una sola vez)
Opción fácil: Netlify Drop
  1. Entrá a https://app.netlify.com/drop (con una cuenta gratis).
  2. Arrastrá ESTA CARPETA completa a la página.
  3. Te da un link (podés cambiarle el nombre, ej. presupuestos-gonzalez.netlify.app).
Opción alternativa: GitHub Pages (subir estos archivos a un repositorio y activar Pages).

INSTALARLA EN EL TELÉFONO
  - Android (Chrome): abrí el link → menú ⋮ → "Instalar app" (o "Agregar a pantalla principal").
  - iPhone (Safari): abrí el link → botón Compartir → "Agregar a pantalla de inicio".
  Funciona sin internet una vez instalada.

GUARDAR EN PDF
  Botón "Imprimir / PDF" → en Destino elegí "Guardar como PDF".
  El archivo toma el nombre del campo "Nombre del PDF".

IMPORTANTE
  Los presupuestos se guardan en cada dispositivo (no se sincronizan entre el
  celu y la PC). Usá "Mis presupuestos → Descargar copia de seguridad" de vez en cuando.

PARA ACTUALIZAR LA APP
  Si cambiás index.html, subí el número de versión en sw.js (v1 → v2) y volvé a publicar.
